# Project Roadmap

## Phase 1: Foundation

- define project vision and requirements
- establish backend API skeleton
- create user, scan, and report models
- implement basic auth flows
- set up environment-driven configuration

## Phase 2: Scanner Core

- build modular plugin framework
- implement header analysis, SSL checks, and technology detection
- aggregate findings into scan results
- establish risk scoring logic

## Phase 3: User Experience

- build front-end dashboard and authentication screens
- connect UI to scan endpoints
- display findings and scan history
- support user profile and password change flows

## Phase 4: Reporting and Intelligence

- improve report generation
- add PDF export capabilities
- develop clearer finding explanations and recommendations
- expand AI-assisted remediation support

## Phase 5: Production Readiness

- tighten security, validation, and observability
- improve deployment settings
- add automated tests and CI processes
- evaluate performance and scalability for larger scan workloads

## Current Focus

The project is currently centered on stabilizing the backend service layer, scan architecture, and documentation alignment while preparing for frontend integration and broader scanning coverage.
